# 客戶資料收集表

## 必備資料

| 項目 | 說明 |
| --- | --- |
| 品牌正式名稱 | 對外呈現名稱；必要時提供登記名稱 |
| 聯絡資訊 | 公開 Email、電話、服務地區或地址 |
| 品牌與服務 | 2–3 句介紹、服務內容、客戶價值 |
| 客戶與目標 | 主要客群、痛點、希望訪客採取的動作 |
| 信任證明 | 可公開的案例、評價、年資、證照或數據 |
| 視覺素材 | Logo、色彩、字體、照片、使用權與風格偏好 |
| 核准人 | 能確認設計、內容與最後發布的人 |

## SEO／AI 搜尋補充資料

| 項目 | 客戶提供內容 |
| --- | --- |
| 主要服務與服務地區 | 每項服務、主要城市／區域；只填實際可服務範圍 |
| 客戶會怎麼搜尋 | 客戶可能輸入的問題、服務名稱、地區詞 |
| 最常見問題與回答 | 至少 3–5 題，以客戶真實回答為準 |
| 可公開的專業證明 | 年資、證照、案例、流程、成果或評價，須能確認真實性 |
| Google 商家檔案／既有網站 | 網址、管理權限狀態；沒有則標記待建立 |

## 追問方式

客戶不知道提供什麼時，使用下列問題：

1. 客戶最常問你的三個問題是什麼？
2. 他們遇到什麼情況才會找你？
3. 你幫他們完成後，有什麼具體改變？
4. 你希望網站訪客下一步做什麼：來電、LINE、填表或預約？
5. 哪些案例、照片與成果可以公開？

缺漏資訊以「待客戶確認」列出，不得自行補寫。

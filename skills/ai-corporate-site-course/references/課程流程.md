# 課程流程

## 交付成果

- Astro 靜態企業網站。
- 品牌資料收集表、內容架構、設計確認稿與核准紀錄。
- GitHub 私有儲存庫（以 GitHub Desktop 操作）。
- Cloudflare Workers 免費部署與暫用網址。
- 選配：正式網域與 `www` 的驗證紀錄。

## 建議順序

```text
收集客戶資料 → 盤點缺漏與訪談 → 網站架構與設計確認稿 → 客戶確認
→ 建立 Astro 網站 → 本機預覽與驗收 → 客戶確認 → GitHub Desktop Commit / Push
→ Cloudflare 自動建置 → 暫用網址驗證 → 正式網域設定與驗證
```

## 技術邊界

純形象網站、服務介紹、FAQ、案例和外部表單不需要資料庫。只有會員、訂單、預約時段、即時庫存、多人後台或大量可搜尋資料時，才另外規劃後端與資料庫。

## 本機驗收重點

檢查首頁、關於、服務、FAQ、聯絡頁；並測試導覽、圖片、CTA、電話、Email、LINE、表單、地圖以及手機版。若本機尚未通過，不能進入發布。

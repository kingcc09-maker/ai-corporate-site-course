# 提示詞庫

## 資料整理

```text
你是企業網站策略與內容顧問。以下是客戶資料：
[貼上資料]
不得自行編造案例、數據、合作品牌、證照或法規內容。
請整理已知資料、網站目標、建議頁面、上線前缺漏與訪談問題。
```

## 設計確認

```text
根據以下品牌資料與網站架構，先不要建立程式碼：
[貼上資料]
請提供首頁、關於、服務、FAQ、聯絡頁的平面設計規格：
區塊順序、色彩 HEX、字體、標題／內文字級、背景與圖片方向、Logo 留白、桌機及手機版差異。
最後列出需客戶確認的設計決策。
```

## 建立本機版本

```text
設計稿已核准。請在 [專案路徑] 建立或更新 Astro 靜態企業網站。
使用 Markdown／JSON 管理內容；保留既有檔案；不建立資料庫、不使用付費服務、不公開部署。
只使用以下已核准資料：[貼上內容]
完成後執行檢查與建置，說明本機預覽網址與修改檔案。
```

## 安全更新

```text
請依「先本機確認、後雲端發布」更新 [專案路徑]。
需求：[內容]
已核准文案／素材：[內容]
先只改本機，完成檢查與本機建置後，列出我需要核對的項目。未經我明確同意，不要 commit、push 或部署。
```
